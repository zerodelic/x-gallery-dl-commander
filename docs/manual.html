X-GALLERY-DL-COMMANDER

// 取扱説明書  |  v1.1.0  |  ローカルアプリ版

📖 このツールについて

X（旧 Twitter）のハッシュタグやユーザーのメディアを、 まとめてダウンロードするための GUI ツールです。
ブラウザで設定を入力して「実行」ボタンを押すだけで、 画像・動画の一括ダウンロードができます。

🗂 2つのエディション
エディション特徴Python
ローカルアプリ版（app/） リアルタイム進捗表示・一時停止・停止ができる本格版 必要
HTML コマンドビルダー版（src/） コマンドを生成してターミナルに貼るシンプル版 不要

このマニュアルは ローカルアプリ版 の説明です。

✅ 必要なもの

ソフトウェアインストール方法確認コマンド
Python 3.10 以上 brew install python python3 --version
gallery-dl brew install gallery-dl gallery-dl --version
Google Chrome X（x.com）にログイン済みの状態であること —
⚠️ ダウンロード実行前に、必ず Chrome で X にログインしておいてください。 gallery-dl は Chrome の Cookie を使って認証します。

🚀 起動方法

  1. app フォルダーを開く
    Finder でプロジェクトフォルダー内の app/ を開きます。
  2. start.command をダブルクリック
    ターミナルが開き、自動でサーバーが起動します。
    初回のみ、依存パッケージ（FastAPI / uvicorn）が自動インストールされます。
  3. ブラウザが自動で開く
    約1.5秒後に http://localhost:8765 がブラウザで開きます。 開かない場合は手動でこの URL にアクセスしてください。
💡 ターミナルウィンドウは閉じずにそのままにしておいてください。 サーバーが動き続けるために必要です。

⚡ クイックプリセット

画面上部の「クイックプリセット」ボタンを使うと、 よく使う設定の組み合わせをワンクリックで呼び出せます。

ボタン設定される内容
📷 ハッシュタグ・画像のみハッシュタグ検索 ＋ 写真のみ
🎬 ハッシュタグ・動画のみハッシュタグ検索 ＋ 動画のみ
📦 ハッシュタグ・全メディアハッシュタグ検索 ＋ 写真・動画
👤 ユーザーのメディアタブユーザー指定 ＋ メディアタブ
❤️ ユーザーのいいねユーザー指定 ＋ いいね一覧
ℹ️ プリセットを選んだあとで、個別の設定を追加変更することもできます。

🎯 取得対象の設定

「取得対象」カードで、何をダウンロードするかを指定します。

＃ ハッシュタグ

ハッシュタグを入力してください。# は不要です。
複数のハッシュタグはカンマ区切りで入力できます。 その場合、ハッシュタグごとにコマンドが生成されます。

入力例
風景写真
風景写真, landscape, 写真好きな人と繋がりたい

👤 ユーザーのメディア / いいね

取得タイプで「ユーザー メディア」または「ユーザー いいね」を選び、 ユーザー名を入力してください。@ は不要です。

入力例
username  （@username の場合は username のみ入力）

📌 単一ツイート

「単一ツイート」を選び、ツイートの URL を貼り付けてください。

🖼 メディア種別

ダウンロードするファイル種別をチェックボックスで選択します。

種別対象形式
📷 写真jpg / png / webp
🎬 動画mp4 / m4v
🎞 GIFアニメgif
ℹ️ 3種別すべてにチェックが入っている場合、フィルターオプションは付加されません（gallery-dl のデフォルト動作）。

📅 日付範囲

「日付範囲を指定する」にチェックを入れると、 投稿日付で絞り込みができます。両方入力する必要はなく、 片方だけでも動作します。

フィールド意味
開始日（以降）指定した日付以降の投稿を取得
終了日（以前）指定した日付以前の投稿を取得

クイック選択ボタン（今月・先月・直近30日など）を使うと 日付を素早く入力できます。

🔢 件数制限

スライダーまたは数字ボタンで最大取得件数を指定します。
0（∞）を選ぶと件数制限なしで取得します。

⚠️ 件数制限なしで大量のメディアを取得すると、 X のレート制限（API 制限）に引っかかりやすくなります。 はじめは 50〜100 件程度でお試しください。

⚙️ オプション

オプション説明推奨
スリープ（流量制限対策） ダウンロードの間隔に2秒の待機を挿入します。レート制限を受けにくくなります。 ✅ ON 推奨
スキップしない すでに保存済みのファイルも再ダウンロードします。通常は OFF で問題ありません。 通常 OFF
最高画質で取得 画像を最高解像度（orig）で取得します。ファイルサイズが大きくなります。 好みで
メタデータを保存（JSON） 投稿者・日時・ツイート ID などをJSON ファイルとして一緒に保存します。 好みで

📝 ファイル名形式 / 保存先

ファイル名形式

モードファイル名の例
標準username_1234567890_1.jpg
日付入り2026-05-10_username_1.jpg
カスタムgallery-dl の変数を使って自由に指定

保存先ディレクトリ

テキストボックスに直接パスを入力するか、 📁 ボタンをクリックしてフォルダー選択ダイアログから選べます。

デフォルト保存先
~/Downloads/x_media

クイック選択ボタン（Downloads / Desktop / Pictures）も使えます。

▶ 実行する

設定が完了したら、進捗パネル上部の ▶ 実行 ボタンをクリックします。
生成されたコマンドが自動的に実行され、進捗パネルにダウンロード状況が表示されます。

// ダウンロード進捗
実行中...
[twitter][info] Downloading 50 images from ...
💡 ダウンロード中にレート制限が発生すると、ステータスバーに
[twitter][info] Waiting for X minutes until HH:MM:SS (rate limit)
と表示されます。自動的に待機し、時間が来たら再開されます。

📊 進捗パネルの見方

ステータスバー

ファイルリストの上の細い帯に、gallery-dl からのメッセージが リアルタイムで表示されます。レート制限待ちのメッセージもここに出ます。

ファイル一覧

ダウンロードされたファイルが1行ずつ追加されます。

アイコン種別
📷写真（jpg / png / webp）
🎬動画（mp4 / webm / mov）
🎞GIFアニメ
ステータス意味
✓ OKダウンロード完了
↷ skipすでにダウンロード済みのためスキップ
✕ errエラーが発生してダウンロードできなかった

フッター

パネル下部にダウンロード済みファイルの合計件数が表示されます。

⏸ 停止・一時停止

ボタン動作
⏸ 一時停止 ダウンロードを一時停止します。もう一度押すと再開します（▶ 再開 に変わります）。
■ 停止 ダウンロードを完全に中止します。途中でダウンロード済みのファイルは残ります。
ℹ️ 一時停止中はファイルのダウンロードが途中で止まります。 再開すると続きから再開されます。

⏻ サーバーの終了

ツールの使用が終わったら、画面右上の ⏻ サーバー停止 ボタンをクリックしてください。
確認ダイアログが表示され、OKを押すとサーバーが終了します。

  1. 「⏻ サーバー停止」ボタンをクリック
  2. 確認ダイアログで「OK」をクリック
  3. 「✅ サーバーを停止しました。このタブを閉じてください。」が表示されたら完了
  4. ブラウザのタブを閉じ、ターミナルウィンドウも閉じる
⚠️ サーバー停止ボタンを使わずにターミナルを閉じた場合、 サーバーがバックグラウンドで動き続けることがあります。 その場合は control + C でターミナルを止めてください。

🔧 トラブルシューティング

ダウンロードが始まらない / 件数が0件

  • Chrome で X（x.com）にログインしているか確認してください
  • ハッシュタグのスペルを確認してください
  • 日付範囲が正しく設定されているか確認してください

「終了コード: 2」が表示される

  • ステータスバーのメッセージを確認してください
  • X の認証エラーの場合は Chrome で再ログインしてください
  • 「最高画質で取得」をオフにして試してみてください

レート制限（Waiting for X minutes...）

  • 表示された時間まで自動で待機します。そのままお待ちください
  • 頻繁に発生する場合は「スリープ」オプションを ON にしてください

ブラウザが自動で開かない

  • 手動で http://localhost:8765 にアクセスしてください

ポート 8765 がすでに使われている

  • app/main.py の最終行のポート番号を変更してください
ℹ️ その他の問題は GitHub Issues にてご報告ください。
